# 医院检查管理系统使用指南

## 一、系统简介

本系统是一套面向医院检验科、检查科室的**检查管理系统**，用于管理患者的检验结果、CT/MRI/病理/肠镜等检查数据，支持批量导入、预警提醒、统计分析等功能。

---

## 二、主界面功能菜单

```
├── 个人信息          # 查看和修改个人账户信息
├── 医嘱信息          # 管理患者的医嘱/处方
├── 检验结果          # 管理检验实验室结果
├── 检查管理          # 管理CT/MRI/病理/肠镜检查
│   ├── CT检查
│   ├── 核磁检查
│   ├── 病理检查
│   └── 肠镜检查
├── 患者信息          # 管理患者基本信息
├── 统计分析          # 数据统计和分析报表
├── 预警记录          # 查看系统预警信息
├── 操作日志          # 查看用户操作记录
└── 系统管理（管理员）  # 系统配置管理
    ├── 参考范围管理
    └── 预警规则配置
```

## 三、功能详解

### 3.1 患者信息管理

**位置：** 菜单 → 患者信息

**功能说明：** 管理患者的基本信息，包括姓名、联系方式、身份证号等。

| 功能 | 操作 | 说明 |
|------|------|------|
| 查看患者列表 | 进入页面默认显示 | 显示所有患者分页列表 |
| 搜索患者 | 输入患者ID或姓名 | 支持模糊搜索 |
| 查看详情 | 点击「详情」按钮 | 查看患者的完整信息 |

**患者完整信息：** 可查看该患者的所有医嘱、检验结果等汇总信息。

## 五、联合检测功能

### 5.1 什么是联合检测？

联合检测使用Isolation Forest（孤立森林）算法，综合分析患者的多项检验指标，检测多指标联合异常模式。

### 5.2 适用场景

- 患者多项指标同时偏高/偏低
- 单项指标正常但多项指标组合异常
- 发现单项检测无法识别的复杂异常模式

### 5.3 操作步骤

1. 进入「检验结果」模块
2. 输入患者ID，点击查询
3. 选择要检测的检验项目（可多选）
4. 点击「联合检测」按钮
5. 系统分析后显示检测结果：
   - **Isolation评分**：0-1之间，越高越异常
   - **综合评分**：结合Z-Score的联合评分
   - **异常等级**：NORMAL（正常）/ SUSPICIOUS（可疑）/ ANOMALY（异常）
   - **异常指标列表**：列出具体哪些指标异常

## 六、预警系统说明

### 6.1 预警触发机制

系统会根据配置的预警规则自动评估新录入的检验和检查数据：

**检验结果预警规则示例：**
- 血糖值超出 3.9-6.1 mmol/L 范围
- Z-Score > 2（偏离均值超过2个标准差）

**检查结果预警规则示例：**
- 报告结论包含"异常"、"可疑"等关键词

### 6.2 预警处理流程

```
数据录入 → 规则评估 → 触发预警 → 通知用户 → 处理预警 → 标记已读
```

### 6.3 重新扫描

如果在配置预警规则之前已有历史数据，可点击「重新扫描」按钮对历史数据进行规则扫描，生成预警记录。

## 七、常见问题

### Q1：新增检验结果时提示"患者不存在"？
**A：** 患者ID必须在「患者信息」模块中先创建。请先到患者信息模块新增该患者。

### Q2：导入数据时提示"项目代码无效"？
**A：** 检验项目代码必须在「参考范围管理」中存在。请检查代码是否正确，或联系管理员添加该项目。

### Q3：导入XML时提示"患者不存在"并弹出新增界面？
**A：** 这是正常流程。系统要求患者ID必须已存在。请先新增患者后再重新导入。

### Q4：趋势分析图没有数据？
**A：** 请确认该患者有此检验项目的历史记录，且时间跨度足够（至少2次检测）。

### Q5：预警规则修改后不生效？
**A：** 规则修改只对新录入的数据生效。如需对历史数据生效，请点击「重新扫描」按钮。

### Q6：数据备份恢复后变成旧数据了？
**A：** 数据恢复会将数据库恢复到备份时的状态，当前数据会被覆盖。这是不可逆操作，请谨慎处理。

## 八、注意事项

1. **患者ID唯一性**：每个患者的ID在系统中必须唯一，不能重复。

2. **数据删除**：删除操作会同时删除关联的PDF报告文件，请谨慎操作。

3. **密码安全**：请定期更换密码，避免账户被盗用。

4. **定期备份**：建议定期进行数据备份，防止数据丢失。

5. **导入文件格式**：Excel文件必须使用标准模板格式，XML文件必须为UTF-8编码。

6. **操作日志**：所有重要操作都会被记录，包括操作人员和时间，请遵守操作规范。
