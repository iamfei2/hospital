# 4.3.3 核心数据表设计

基于医院检查数据的业务特性，系统设计了 17 张核心数据表，各表的结构与用途如下。

用于存储患者的基础档案信息，是所有检查、检验、医嘱数据的关联核心，其结构如表 4-5 所示。

表 4-5 patient 患者信息表

| 字段名 | 数据类型 | 字段说明 | 约束 |
|--------|----------|----------|------|
| patient_id | varchar(20) | 患者编号（病案号），主键 | 主键，非空 |

| gender | char(2) | 性别（男 / 女） | |
| age | int | 年龄 | |
| phone | varchar(500) | 联系电话，AES 加密存储 | |
| id_card | varchar(500) | 身份证号，AES 加密存储 | |
| is_invalid | tinyint(1) | 逻辑删除标识 | 非空，默认 0（0=有效，1=作废） |

| update_time | datetime | 更新时间 | 非空，默认 CURRENT_TIMESTAMP |
