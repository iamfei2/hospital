# 医院检查数据管理平台 — 系统详细功能介绍

## 1.0 系统概述

本系统是一套面向医院检查科室的检查数据管理平台，覆盖患者就诊过程中"登记患者档案 → 录入检查结果 → 查阅检验报告 → 统计工作量 → 异常预警提醒 → 数据安全维护"的全业务流程。系统采用浏览器访问方式，不同角色（管理员、医生、检验技师、审计员）登录后拥有不同的操作权限。

---

## 1.1 管理患者信息

### 1.1.1 登记患者档案

医护人员可为初次就诊的患者创建电子档案，录入姓名、身份证号、性别、出生日期、联系方式、家庭住址等基本信息。录入后系统自动生成唯一的患者编号，后续所有检查和检验数据均与该编号关联。

### 1.1.2 修改患者资料

当患者联系方式变更、住址迁移等信息需要更新时，可直接在患者信息页面修改并保存，修改内容会记录到操作日志中，确保每次变更都有据可查。

### 1.1.3 搜索患者

支持按患者姓名（模糊匹配）或患者编号进行快速检索，输入关键字后系统返回匹配的患者列表，点击即可查看详细信息，无需在海量记录中逐页翻找。

### 1.1.4 查看就诊汇总

选中患者后可一键查看其"就诊全景图"：系统自动汇总该患者在本院的所有 CT 检查、核磁检查、病理检查、肠镜检查、检验结果以及医嘱记录，按时间顺序排列，方便医生在接诊时快速了解患者的完整诊疗历史。

---

## 1.2 管理检查记录

### 1.2.1 录入检查记录

支持录入四类医技检查记录：

| 检查类型 | 录入内容 |
|----------|----------|
| CT 检查 | 患者编号、检查编号、检查时间、检查部位（如胸部、腹部）、检查医生、所属科室、报告结论 |
| 核磁共振 | 患者编号、检查编号、检查时间、检查部位、检查医生、所属科室、报告结论 |
| 病理检查 | 患者编号、检查编号、检查时间、检查医生、所属科室、镜下所见与诊断结论 |
| 肠镜检查 | 患者编号、检查编号、检查时间、肠镜类型（普通 / 无痛）、操作医生、所属科室、镜下诊断 |

### 1.2.2 上传报告附件

每份检查记录可上传对应的报告 PDF 文件与影像图片（CT 的 DICOM 影像、肠镜的镜下照片等），所有附件随检查记录一同归档存储。支持多张图片批量上传。

### 1.2.3 下载调阅报告

已上传的报告 PDF 和影像图片支持在线预览和下载，医生无需翻查纸质档案或登录其他系统即可直接调阅。

### 1.2.4 修改与作废记录

检查记录录入有误时可随时编辑更正；对不再需要的记录可执行作废操作。系统采用逻辑删除机制——作废的记录不会从数据库中物理删除，标记为无效后仍可追溯查询，误操作时支持恢复。

### 1.2.5 组合查询记录

在检查列表页面提供多条件组合筛选功能，支持同时按患者编号、患者姓名、检查编号、检查部位、检查医生、所属科室、检查时间范围等多个条件进行筛选。条件越多，结果越精确。

---

## 1.3 管理检验结果

### 1.3.1 录入检验结果

检验技师收到样本后，在系统中选择对应的患者和检验项目（如白细胞计数、血红蛋白、血糖、肌酐等），输入检验结果值和单位，保存即可完成录入。系统会自动与该项目配置的参考范围进行比对。

### 1.3.2 批量登记项目

当同一患者一次采样需要检测多个项目时（如血常规包含十几项指标），可使用批量登记功能：一次性勾选所有需要登记的检验项目，填入对应的结果值，统一提交保存，大幅减少逐条录入的重复操作。

### 1.3.3 上传检验报告

支持将检验报告 PDF 上传至系统中，与对应的检验结果记录关联存档，便于随时调阅原始报告。

### 1.3.4 查看指标趋势

选中患者和某项检验指标后，系统会自动调取该患者该指标的全部历史记录，并以折线图的形式直观展示变化趋势。医生可以一眼看出指标是在持续升高、逐渐下降还是趋于稳定，为病情判断提供直观依据。

### 1.3.5 联合检测异常

对于需要综合多项指标才能判断的复杂情况（如肝肾功能需同时观察多项指标），系统提供联合异常检测功能。后台首先使用 Z-Score 方法量化每项指标偏离正常的程度，再使用孤立森林算法从多指标组合维度进行综合评估，最终给出"正常 / 可疑 / 异常"的判断结论，并列出具体的问题指标清单，辅助医生快速定位。

---

## 1.4 管理医嘱信息

### 1.4.1 开具新医嘱

医生接诊后可在线为患者开具医嘱，填写医嘱内容（如用药方案、检查项目、护理要求等），指定执行科室，系统自动记录开嘱医生和开嘱时间。

### 1.4.2 修改与查询医嘱

已开具的医嘱支持修改和查看，所有医嘱按时间排序分页展示，方便医嘱管理和交接班查阅。

---

## 1.5 批量导入数据

### 1.5.1 导入 Excel 历史数据

医院科室在系统上线前积累了大量的历史检查数据（通常以 Excel 文件形式保存），系统提供专门的批量导入工具，支持 CT 检查、核磁检查、病理检查、肠镜检查、检验结果共五类数据的分别导入。用户只需按模板整理好 Excel 文件，选择文件上传即可，30 秒内可完成数万条数据的导入。

### 1.5.2 选择导入模式

系统提供两种导入模式供用户选择：

- **严格模式**：遇到任何数据问题（格式错误、缺失必填项等）即停止全部导入，确保入库数据零差错。
- **跳过模式**：自动跳过有问题的数据行，其余正常行继续导入，适合大量数据中有少量瑕疵时需要快速完成主体导入的场景。

### 1.5.3 自动校验数据质量

导入过程中系统会自动进行三道数据校验：

1. **格式校验**：检查日期格式是否规范、必填字段是否缺失等。
2. **范围校验**：检查数值是否在合理范围内，异常偏离的数据会被标记。
3. **重复检测**：如果同一条检查记录（按检查编号 + 患者 + 检查时间联合判定）已经存在于系统中，自动跳过，不会重复导入。

### 1.5.4 查看导入报告

导入完成后系统会生成一份完整的导入报告，清晰展示：总共读取了多少条、成功导入了多少条、跳过了多少条、失败了多少条。其中失败的数据行可一键下载为 CSV 文件，文件中标注了行号和失败原因，方便数据管理员对照修正后重新导入。

### 1.5.5 导入 XML 格式数据

除了 Excel 格式，系统还支持 XML 格式的检查数据批量导入。XML 数据通常来自其他医疗系统（如 HIS、LIS）的数据导出，系统会自动解析 XML 中的患者信息字段和检查结果字段，完成数据迁移。同样支持五类检查数据，重复记录自动跳过，并支持下载标准 XML 导入模板。

### 1.5.6 导出数据至 Excel

用户可将当前查询到的检查记录或检验结果一键导出为 Excel 文件，用于制作纸质报表、跨系统数据交接或科研成果整理。

## 1.6 统计数据分析

### 1.6.1 按时间统计

管理人员可以查看科室检查量在不同时间维度下的变化趋势，支持按日、周、月、年以及自定义时间段进行统计。例如可以快速了解本月比上月的检查量增长了多少。

### 1.6.2 按科室统计

系统支持按执行科室（如放射科、消化内镜科、病理科、检验科等）分别统计检查数量和工作量，便于科室绩效考核和资源配置。

### 1.6.3 按类型统计

可查看 CT 检查、核磁检查、病理检查、肠镜检查、检验结果各占多少比例，以饼图的形式直观展示检查类型的构成分布。

### 1.6.4 按医生统计

统计每位医生完成的工作量（检查数量和检验结果数量），自动生成工作量排名，为医生的绩效考核提供数据参考。

### 1.6.5 查看可视化图表

统计结果以多种图表形式直观呈现：

- **柱状图**：月度检查量对比，一眼看出工作量的周期性变化
- **饼图**：检查类型占比分布
- **折线图**：某项指标的历史趋势
- **排行表格**：医生工作量排名

所有图表均基于 ECharts 动态渲染，支持交互式查看。

### 1.6.6 导出统计报表

统计结果支持一键导出为 Excel 格式，科室主任可直接用于月度工作汇报、年终总结等场景。

## 1.7 监控异常预警

### 1.7.1 配置预警规则

管理员或检验技师可以为各项检验指标配置预警规则，设定指标的阈值范围（如白细胞计数正常范围为 4.0~10.0 ×10⁹/L，超过 20.0 则触发高危预警）。配置后系统会定时自动扫描新入库的检验数据，命中规则的记录将自动生成预警。

### 1.7.2 配置联合检测规则

对于需要多个指标组合分析才能发现的潜在异常（如某些疾病在单指标上表现不明显，但多指标共同偏离时会形成一种"异常模式"），系统支持配置孤立森林联合检测规则。选定需要组合分析的指标后，系统会从历史数据中自动学习"正常模式"，再用于检测新数据。

### 1.7.3 接收实时预警

当新录入的检验结果触发了预警规则或异常检测模型时，系统会通过 WebSocket 技术将预警消息即时推送到当前在线用户的浏览器页面。无需手动刷新，预警通知自动弹出，确保医护人员第一时间知晓。

### 1.7.4 查询预警记录

所有历史预警记录均可追溯查询，支持按时间范围（最近一小时、今天、本周等）、按异常等级（异常 / 可疑 / 正常）、按患者编号等多种条件筛选，方便回顾和审核。

## 1.8 维护系统安全

### 1.8.1 管理用户权限

系统预设四种角色，分配不同的操作权限：

| 角色 | 权限范围 |
|------|----------|
| 系统管理员 | 拥有全部权限，可管理用户、配置系统参数、执行备份恢复 |
| 医生 | 可查看和录入检查与检验数据、查看统计报表、导出数据，不可删除他人数据 |
| 检验技师 | 可管理检验结果、配置检验项目参考范围、管理预警规则 |
| 审计员 | 只读权限，专门负责审查操作日志和审计记录 |

在角色权限基础上，系统还支持 16 项细粒度操作权限控制（如"谁能查看 CT 检查"、"谁能导入数据"、"谁能管理备份"等），可按需灵活调配。

### 1.8.2 追溯操作日志

系统中每一次新增、修改、删除、导入、备份操作都会被自动记录下来。记录内容包括：谁操作的、什么时间、从哪个 IP 地址、做了什么操作、操作前后的数据分别是什么。所有操作日志不可删除、不可篡改，满足医疗行业对数据操作"全程留痕、100% 可追溯"的合规要求。管理员和审计员可按操作人、操作类型、时间范围筛选查看。

### 1.8.3 自动备份数据

系统每天自动执行两次数据库备份：

- **凌晨 2:00** —— 全量备份，将整个数据库完整导出
- **中午 12:00** —— 增量备份，仅备份自上次全量备份以来的数据变更

备份文件使用 AES 算法加密并 GZIP 压缩后存储，防止泄露。系统自动保留最近 30 份全量备份，超过的部分自动清理，避免占用过多磁盘空间。管理员也可以随时手动触发备份。

### 1.8.4 恢复数据库

当发生数据误删或系统故障需要恢复数据时，可从备份文件列表中选择目标备份文件执行恢复。为防止误操作，系统要求输入动态生成的确认验证码，验证码 5 分钟内有效，验证通过后方可执行恢复操作。

### 1.8.5 配置检验参考范围

系统管理员或检验技师可以维护检验项目字典，包括项目名称、项目编码、默认单位、正常参考范围（上下限）、备注说明等。参考范围的配置直接关系到预警系统能否准确判断"正常"与"异常"。

### 1.8.6 保护患者隐私

系统从多个层面保护患者隐私数据：

- **存储加密**：患者的身份证号、手机号等敏感字段在数据库中使用 AES 算法加密存储，即使数据库文件泄露也无法直接读取原始信息。
- **展示脱敏**：在页面展示时，姓名（保留首尾字）、身份证号（中间打码）、手机号（中间四位隐藏）自动脱敏处理。
- **接口限流**：对外 API 接口配置了独立的调用频率限制，防止恶意高频访问。

## 1.9 提供外部接口

### 1.9.1 管理接口访问凭证

外部系统（如医院 HIS 系统、电子病历系统）如果需要调用本平台的数据接口，需先申请 API 访问凭证，包括 API Key 和 API Secret 双凭证。系统管理员可为每个应用分配独立的凭证，并设置每分钟的调用次数上限，确保接口不被滥用。

### 1.9.2 提供患者数据查询

系统对外提供标准的 RESTful 查询接口，外部系统在携带有效凭证的情况下，可按患者编号获取该患者在本平台的完整检查数据汇总，包括 CT、核磁、病理、肠镜检查记录和检验结果。返回数据中的敏感字段（身份证号、手机号等）已自动脱敏处理。接口文档通过 Swagger 自动生成，第三方开发人员可直接查阅和调试。

### 1.9.3 保存与共享查询模板

医护人员在日常工作中经常使用相同的组合条件查询数据（如"查找放射科本月所有胸部 CT 检查"），系统支持将当前设置好的查询条件保存为一个查询模板，下次直接应用即可，无需重复输入。模板支持在团队成员之间共享，一个人的常用查询其他同事也能一键复用。支持 CT、核磁、病理、肠镜、检验共五类检查的查询模板。
